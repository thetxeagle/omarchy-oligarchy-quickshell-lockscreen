# Session: Configurable Lock Timer, Color, and Blurred Background

**Date**: 2026-09-13
**Branch**: main
**Project**: `omarchy-oligarchy-quickshell-lockscreen`
**Duration**: implementation slice

## Summary

Added per-user `~/.locktimer` and `~/.lockcolor` settings to the stock-derived
lock lifecycle and restored stock Omarchy's blurred-current-wallpaper treatment
behind the custom Oligarchy composition. These changes do not reload Hyprland,
cycle outputs, change monitor geometry, or replace stock wake behavior.

## Work Completed

- Replaced the fixed 25-second timer with a delay read from `~/.locktimer`.
- Defined `0` as indefinitely visible and positive whole numbers as seconds.
- Retained 25 seconds as the fallback for missing or invalid values.
- Re-read the value on every lock so changes apply without a plugin restart.
- Exposed the effective delay through the existing lock status IPC response.
- Added stock Omarchy's cache-busted, aspect-cropped wallpaper and `MultiEffect`
  blur behind the existing lockscreen layout.
- Added a 20-choice `lockcolor.example` palette and routed all normal accent
  elements through the one active `~/.lockcolor` entry.
- Retained the current Omarchy accent when the color file is missing, invalid,
  empty, or ambiguous.
- Documented timer behavior and wallpaper rendering, then updated the changelog
  and scratchpad.

## Decisions Made

- Keep Omarchy's stock authentication, session-lock, DPMS blank, wake, and
  stranded-lock recovery lifecycle intact.
- Parse the file as data and accept only non-negative whole numbers.
- Cap values at 2,147,483 seconds because QML timer intervals are milliseconds.
- Avoid a file watcher; lock activation is the natural configuration boundary.
- Reuse stock Omarchy's wallpaper loading and exact blur parameters rather than
  introducing a separate rendering or compositor effect.
- Treat palette lines beginning with `#` as disabled and require exactly one
  uncommented six-digit hex value before overriding the Omarchy accent.
